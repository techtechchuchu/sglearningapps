# 대학생 공식 모의고사 운영 메모

이 기능은 기존 변형 퀴즈와 별개입니다. 문제 본문은 공개 코드에 있지만 정답은 공개 저장소에 넣지 않습니다.

## 최초 개설

1. `supabase/migrations/20261025_university_mock_attempts.sql`을 운영 데이터베이스에 적용합니다.
2. 서버 환경 변수 `UNIVERSITY_MOCK_OPEN_AT`, `UNIVERSITY_MOCK_CLOSE_AT`에 ISO 8601 날짜·시각을 입력합니다. 두 시각 사이가 실제 응시 기간이며, `CLOSE_AT`은 `OPEN_AT`보다 뒤여야 합니다.
3. 서버 비밀 환경 변수 `UNIVERSITY_MOCK_ANSWER_KEY`에 문제 1~8번 정답의 **0부터 시작하는 선택지 번호**를 쉼표로 구분해 입력합니다. 이 값은 Git·문서·브라우저 코드에 넣지 않습니다.
4. 정답을 별도로 검산하고, 테스트 계정으로 시작 → 답안 저장 → 1회 제출 → 종료 후 익명 순위 공개를 확인한 뒤 실제 응시 기간을 알립니다.

세 값 중 하나라도 빠졌거나 형식이 틀리면 학생 화면에는 ‘준비 중’만 표시되고 응시는 열리지 않습니다. 시작 후 제한 시간은 30분이며, 마감이 더 이르면 마감 시각에 끝납니다. 시간 초과 시 마지막으로 서버에 저장된 답안으로 자동 제출됩니다.

동일한 `exam_slug`로 다시 시험을 열면 이전 응시 기록 때문에 재응시할 수 없습니다. 다음 회차는 새 slug와 별도 문항·정답으로 개설해야 합니다.
